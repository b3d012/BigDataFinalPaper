Retraining Protocol:
Shadow Model Approach: The system must not stop the live capture during retraining. Codex should ensure that the new model is trained in the background while live inference continues. The updated model is validated against performance targets (e.g., PR-AUC > 0.92) and then swapped into the live inference thread without downtime.
Hot-Swapping: Codex should immediately swap the retrained model into the live pipeline, replacing the old one seamlessly.

SMOTE Application: Codex must apply SMOTE oversampling only to the training split. It must never apply SMOTE to the validation or test splits to avoid data leakage.
Cost-Sensitive Learning: Codex must calculate scale_pos_weight dynamically based on the per-class benign-to-attack ratio, ensuring that the loss function penalizes false negatives for high-severity attack categories.
